
# JavaScript Async Lab

A hands-on learning repository exploring JavaScript execution, callbacks,
Promises, async/await, the event loop, and concurrency.

## Learning approach

Every experiment follows this process:

1. Predict the output.
2. Run the code.
3. Observe the execution order.
4. Explain why it happened.
5. Modify the code and test again.
